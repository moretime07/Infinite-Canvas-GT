# 无限画布“跟随默认 API”设计

## 目标

让无限画布的新建 API 生图、LLM 和视频节点默认跟随全局主供应商，同时保留节点级手动覆盖能力。全局主供应商改变时，只更新仍处于“跟随默认 API”模式的节点，不覆盖用户手动选择，也不迁移现有节点。

## 状态模型

三类通用 API 节点新增持久化字段：

```text
providerMode: "default" | "fixed"
```

- `default`：节点跟随全局主供应商，并按节点能力解析实际供应商和模型。
- `fixed`：节点使用自己保存的供应商与模型，不受全局主供应商变化影响。
- 旧画布中缺少 `providerMode` 的节点按 `fixed` 处理，确保升级不会改变已有工作流。

字段映射：

| 节点类型 | 供应商字段 | 模型字段 | 能力 |
|---|---|---|---|
| API 生图 `generator` | `apiProvider` | `model` | `image_models` |
| LLM `llm` | `llmProvider` | `model` | `chat_models` |
| 视频 `video` | `apiProvider` | `model` | `video_models` |

## 新建与切换行为

- 新建三类节点时写入 `providerMode: "default"`。
- 节点创建时立即解析当前能力兼容的主供应商，并把真实供应商 ID 与首个兼容模型写入现有字段；后端请求格式不变。
- 供应商下拉框首项显示 `跟随默认 API（供应商名称）`，其值使用仅限前端 UI 的稳定哨兵值 `__default__`。
- 选择具体供应商后写入 `providerMode: "fixed"`，并选择该供应商的首个兼容模型。
- 重新选择 `跟随默认 API` 后写入 `providerMode: "default"`，立即解析当前主供应商及兼容模型。
- 模型仍可由用户在当前解析出的供应商范围内手动选择；当默认供应商变化且原模型不兼容时，切换为新供应商的首个模型。

## 全局默认变化

无限画布收到 `providers-changed`、`canvas-focus` 或配置刷新时：

1. 重新加载供应商配置。
2. 只遍历 `providerMode === "default"` 的三类节点。
3. 按图片、聊天或视频能力选择当前主供应商；若主供应商不兼容，沿用 `ProviderDefaults.pickProvider` 的兼容回退规则。
4. 更新节点的真实供应商 ID。
5. 当前模型仍属于新供应商时保留，否则选取首个兼容模型。
6. 重新渲染；仅在解析结果实际变化时调度画布保存。

`fixed` 节点和缺少 `providerMode` 的旧节点不修改。

## 界面与可访问性

- 三类节点的供应商下拉框均提供首项 `跟随默认 API（名称）`。
- 跟随模式下，下拉框显示该首项，而不是把节点误显示为固定选择。
- 固定模式下显示具体供应商。
- 选项使用原生 `<select>`，保留键盘操作和现有事件传播保护。
- 当没有兼容供应商时，跟随选项仍显示，但节点模型为空并沿用现有“暂无模型”提示；运行时继续使用现有明确错误，不触发错误供应商。

## 数据流与兼容性

- `providerMode` 随画布节点 JSON 正常保存，不需要后端数据库或接口迁移。
- 实际生成、聊天和视频请求继续发送真实 `provider_id` 和模型，不发送 `__default__`。
- 加载旧画布时不补写 `providerMode`，因此不会因为打开画布而产生无意义保存或迁移。
- 复制、撤销、远程同步和画布导入沿用节点 JSON，自然保留跟随/固定状态。

## 测试与验收

新增行为测试覆盖：

- 三类新节点均写入 `providerMode: "default"` 并解析为 OpenRouter 主供应商。
- 三类下拉框均包含可见的跟随默认选项。
- 选择具体供应商切换为 `fixed`；选择哨兵值切回 `default`。
- 全局主供应商变化只更新 `default` 节点，旧节点和 `fixed` 节点保持不变。
- 新主供应商不支持节点能力时使用兼容回退。
- 模型兼容时保留，不兼容时回落到首个模型。
- 所有请求路径都不会发送 `__default__`。
- 现有供应商默认、OpenRouter、画布和智能画布回归测试继续通过。

手工验收不点击生成、发送或运行：新建三类节点，确认均显示 `跟随默认 API（OpenRouter）`；将其中一个节点改为固定供应商，再切换全局主供应商，确认只有另外两个跟随节点变化。

## 非目标

- 不自动转换任何已有节点。
- 不批量重写历史画布。
- 不改变智能画布、在线生图或 GPT 对话的现有默认逻辑。
- 不改变后端生成接口或供应商密钥存储方式。
