# Infinite Canvas 自由连线与循环运行守护设计

## 目标

统一无限画布的连线规则，让旧画布和新画布表现一致：

- 任意两个不同节点，只要源节点有输出端口、目标节点有输入端口，就允许建立连线。
- 允许 `LLM → 视频生成 → LLM` 等反馈闭环。
- 打开或同步旧画布时，不再因为当前节点类型白名单或闭环检查而删除有效连线。
- 一键运行遇到闭环时必须提示用户，不允许静默陷入无限循环。

## 非目标

- 不允许节点连接到自身。
- 不为反馈连接增加单独的连线类型、颜色或额外配置。
- 不自动重复运行闭环。
- 不改变无环工作流现有的一键运行顺序和单节点运行方式。

## 根因

当前 `canConnect()` 同时承担两类职责：

1. 判断界面是否允许创建连线。
2. 判断执行图是否允许包含生成节点循环。

当画布中已经存在 `LLM → 视频生成` 路径时，建立 `视频生成 → LLM` 会被
`wouldCreateGeneratorCycle()` 拒绝。不同画布已有路径不同，因此相同的拖线操作表现不一致。

此外，`sanitizeConnections()` 在打开画布、远程同步画布时重新调用 `canConnect()`。
这会让已保存的旧连线因当前白名单或循环规则变化而被静默删除。

## 方案

### 1. 分离结构校验与执行校验

新增清晰的两层职责：

- `canStructurallyConnect(fromId, toId)`：只检查节点存在、节点不同、源节点有输出能力、目标节点有输入能力。
- `analyzeWorkflowCycles(anchorId)`：只在一键运行前分析可执行节点构成的依赖图，返回循环路径。

交互拖线、快捷创建连线和旧画布清理只使用结构校验，不再调用循环校验。

### 2. 统一节点端口能力

使用单一能力函数作为端口渲染和结构连线判断的来源：

- `nodeCanReceive(node)`：节点是否存在输入端口。
- `nodeCanEmit(node)`：节点是否存在输出端口。

能力以实际端口为准，不再为 `generator`、`video`、`rh`、`llm` 等组合维护多处分散白名单。
没有输入端口或输出端口的节点仍不能从错误方向连接。

### 3. 保留旧画布连线

`sanitizeConnections()` 仅删除：

- 源节点或目标节点已不存在的孤儿连线；
- 节点连接自身的连线；
- 完全重复的连线。

合法的旧连接即使形成反馈闭环也必须保留。命名输出端口的 `fromPort` 信息必须保留，并参与重复判断。

### 4. 目标节点按需消费数据

连线表示“允许目标节点读取源节点的数据”，而不是强制一种固定数据类型：

- LLM 从所有直接上游收集可用文本、图片和视频。
- 图片、视频和其他生成节点从上游收集自己支持的提示词与媒体引用。
- 目标节点不支持的数据被忽略，但连线本身保留。
- 运行时若目标节点没有任何可用输入，沿用或补充明确的“缺少提示词/素材”错误，不以删线代替错误提示。

### 5. 闭环检测与提示

一键运行前，对本次工作流涉及的可执行节点建立依赖图并检测循环。

发现循环时弹出确认提示，内容包括：

- “检测到反馈回路，本工作流不能自动无限循环”；
- 一条可读循环路径，例如 `LLM → 视频生成 → LLM`；
- “仅运行一轮”按钮；
- “取消运行”按钮。

选择“仅运行一轮”后：

- 本轮中每个可执行节点最多运行一次；
- 使用确定性的现有画布/依赖顺序执行；
- 因反馈边而尚未产生的新数据可以使用节点已有的上轮输出；
- 不自动开启第二轮。

选择“取消运行”后不启动任何节点。

单独点击某个节点的运行按钮不递归执行整张图，因此不显示闭环提示。

### 6. 兼容性

- 无环工作流执行行为保持不变。
- 旧画布首次打开时不自动重写或删除反馈线。
- 远程画布同步、复制粘贴、工作流导入与撤销恢复使用相同结构校验。
- 连接创建后仍立即保存并刷新目标节点输入预览。

## 错误处理

- 拖线失败时若原因是节点不存在、同一节点或端口方向错误，显示简短状态提示，不再静默失败。
- 循环检测失败时阻止一键运行并显示可读错误，不尝试猜测执行顺序。
- 循环路径过长时展示首条完整路径，并说明可能还存在其他反馈回路。

## 测试

新增或扩展前端行为测试，至少覆盖：

1. 已存在 `LLM → 视频生成` 时，仍可建立 `视频生成 → LLM`。
2. API 图片、视频、RunningHub、ComfyUI、ModelScope、动作提取和 Output 节点均可连接到 LLM。
3. 旧画布中的反馈连线经过 `sanitizeConnections()` 后仍被保留。
4. 孤儿、自连和重复连接会被清理。
5. 无环工作流不显示循环提示，执行顺序不变。
6. 闭环工作流返回可读循环路径。
7. 用户取消时不执行节点。
8. 用户选择“仅运行一轮”时，每个可执行节点最多执行一次。
9. LLM 能从放宽后的上游连接读取文本、图片和视频。

## 验收标准

- 相同节点组合在所有新旧画布中均可建立并保留连线。
- `视频生成 ↔ LLM` 双向反馈连接能够保存、刷新页面后仍存在。
- 一键运行反馈闭环前必定提示，不会无限调用节点。
- 用户选择“仅运行一轮”后任务能结束，且不存在同一节点在该轮重复执行。
- 现有无环工作流和相关自动测试不回归。
