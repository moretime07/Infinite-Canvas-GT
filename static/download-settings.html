上传/下载代理

为素材云端上传和生成视频下载选择代理线路；独立开关，共用下方地址和端口，不改变模型调用或系统代理。

作用于运行后台的电脑

例如后台运行在 5080 电脑上，127.0.0.1 就是那台电脑，不是局域网同事的电脑。设置仅保存在后台本机，不会随画布导出。

服务器只填 IP 或主机名。端口须与代理软件中一致，例如 10808 或 7890；不是 VPN 订阅地址。此处不支持需要账号密码的代理。

HTTP 代理也可访问 HTTPS 上传服务和视频地址，不必因此选择 HTTPS 协议。代理可看到传输目标和流量信息，请只使用可信代理。保留 TLS 证书验证，失败不会静默切换直连。云端上传仍使用第三方临时存储，知道素材直链的人可访问；代理不会将素材变成私有。

测试仅通过填写的代理访问 Google 的公开连通性测试地址，不发送 API Key、提示词或素材；不会消耗生成额度，也不保证上传服务可用或实际 CDN 下载速度。

怎么填写？

  1. 在运行后台的电脑上启动你已有的代理软件。
  2. 查看它的 HTTP／混合端口或 SOCKS5 端口，选对应协议。
  3. 通常服务器填 127.0.0.1，端口按代理软件填写。
  4. 按需勾选素材上传、视频下载，测试连接，再保存。已有传输不会中断或重新提交生成。

上传开关只作用于 Litterbox / Temp.sh 云端中转，不影响向画布添加本地文件、供应商专用上传接口、提交生成、轮询、图片下载或本地文件导出。下载开关保持原有范围。内网 IP 和 localhost 地址保持直连；关闭对应开关后恢复原有网络策略。局域网用户需由后台电脑的管理员设置。

上传返回 403 表示访问被拒绝，可检查代理出口或改用自己的公网存储；500 等服务异常通常需要稍后重试，开启代理不能保证修复服务端故障。
