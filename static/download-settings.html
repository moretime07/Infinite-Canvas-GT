视频下载代理

为生成视频的下载选择代理线路，不改变模型调用或系统代理。

作用于运行后台的电脑

例如后台运行在 5080 电脑上，127.0.0.1 就是那台电脑，不是局域网同事的电脑。设置仅保存在后台本机，不会随画布导出。

服务器只填 IP 或主机名。端口须与代理软件中一致，例如 10808 或 7890；不是 VPN 订阅地址。此处不支持需要账号密码的代理。

HTTP 代理也可以下载 HTTPS 视频，不必因为视频地址是 HTTPS 就选择 HTTPS 协议。启用后，代理能看到下载目标和流量信息；请只使用你信任的代理。保留 TLS 证书验证，不会静默切换直连。

测试仅通过填写的代理访问 Google 的公开连通性测试地址，不发送 API Key、提示词或素材；不会消耗生成额度，也不代表实际 CDN 下载速度。

怎么填写？

  1. 在运行后台的电脑上启动你已有的代理软件。
  2. 查看它的 HTTP／混合端口或 SOCKS5 端口，选对应协议。
  3. 通常服务器填 127.0.0.1，端口按代理软件填写。
  4. 勾选启用，测试连接，再保存。已有下载不会中断或重新计费。

此设置只代理下载生成的视频，不代理上传素材、提交生成、轮询、图片下载或本地文件导出。关闭自定义代理后恢复原有网络策略。局域网用户需由后台电脑的管理员设置。
