# 无限画布 Windows 完整便携版

## 直接使用

1. 将整个 ZIP 解压到可写、路径较短的目录，例如 `D:\Infinite-Canvas-GT`。不要直接在压缩包中运行，不要放到 Program Files，也不要只复制 EXE。
2. 双击根目录的 **InfiniteCanvas.exe**。它会启动内置 Python，并打开浏览器中的画布。
3. 在网页「API 设置」填写自己的平台地址、协议和 API Key。云端生成需要联网，并可能消耗供应商余额。
4. 要关闭后台，点击启动器的「停止此后台」。关闭浏览器不会停止后台；关闭启动器时可以选择是否同时停止。

这个包已包含 Python、基础依赖、视频处理工具、Git、PyTorch CUDA 12.8、ONNX Runtime CUDA 12、深度白模/骨骼姿态的三份模型及配套源码。普通使用不需要运行「安装依赖」或安装系统 Python。不要删除配套的 python、bin、static、tools、motion_extractor 和 data/motion_models 文件夹。

## 仍然由使用者提供的东西

- **系统**：Windows 10/11 64 位及系统自带的 .NET Framework 4.x。不是 macOS、ARM64 或 32 位版本。
- **显卡驱动**：本地深度白模需要兼容 CUDA 12.8 的 NVIDIA 显卡和驱动，以及足够显存。本包不安装显卡驱动；已在 RTX 5080 上测试，不保证所有显卡都支持。没有兼容 GPU 时，仍可使用普通画布和云端模型接口。
- **第三方账号**：API Key、登录授权、供应商余额需要本人提供，包中没有作者的账号或 Key。
- **外部服务**：RunningHub/云模型仍访问对应服务。ComfyUI 是独立服务，用户自己的工作流插件和大模型不包含在本包里。即梦 CLI 仍需要 WSL/Ubuntu 及本人登录，可按随附脚本单独配置；不能把作者的 WSL 系统和登录态一起复制给同事。

## 隐私与分享

EXE 默认只监听本机 `127.0.0.1:3000`，不会因为双击启动就向局域网开放个人数据。每个同事在自己的电脑运行自己的文件夹。

原始发行 ZIP 不含 API/.env、个人画布、提示词历史、上传素材、生成结果或登录信息。包里的 data/motion_models 仅为校验过的公开模型和公开源码。

**使用后，这个文件夹会产生个人资料。给同事转发时请发原始 ZIP，不要把自己用过的文件夹重新压缩发送。** API/.env 是本机明文 Key 文件，应保护目录权限。data、assets、output、history.json、global_config.json 以及运行日志可能含个人资料。

## 更新、迁移和故障

- 网页程序更新会保留本机数据。EXE 启动器及内置 Python/GPU/视频工具的升级，请使用新版完整便携包；先备份 API、个人 data、assets 和 output，不要把旧 Python 环境覆盖到新包里。
- 便携包内的源代码版本与构建资源清单见 PORTABLE_COMPONENTS.json。基础安装依赖文件是版本范围，已打包的实际版本另记录在 PORTABLE_PYTHON_PACKAGES.json。
- 提示端口占用：先停止旧版后台，再启动便携版。启动器不会强制杀掉其他安装目录的进程。必要时通过命令行 `InfiniteCanvas.exe --port 3001` 使用其他端口。
- 提示缺少文件：重新完整解压，不要只复制 EXE。可把整个文件夹搬到其他目录，但不能拆分内部结构。
- Windows 可能因为自制启动器没有商业代码签名而显示未知发布者。请核对来源、文件校验和或联系公司 IT；不要关闭杀毒软件或全局安全检查。
- 本机运行日志可从启动器打开。日志不应直接公开转发，其中可能有任务内容、路径或临时资源 URL。
- 深度白模默认开启，骨骼和音频保留按节点开关控制；视频尺寸/帧数限制沿用画布本身的规则，打包不改变模型能力。
